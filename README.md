# Starbucks Financial Statement Analysis (FY2021–FY2023)

**Financial Analysis & Excel Modeling**

## Project Overview
An Excel-based financial statement analysis project examining Starbucks' financial performance across fiscal years 2021–2023.

The model organizes key financial statements and applies financial analysis techniques to evaluate profitability, financial position, cash flow generation, and operating performance.

## Key Components
- Income Statement Analysis (FY2021–FY2023)
- Balance Sheet Analysis (FY2022–FY2023)
- Cash Flow Statement Analysis (FY2021–FY2023)
- Financial ratios and performance indicators
- Common-size financial statement analysis
- Cash flow and Free Cash Flow analysis
- Formula-driven calculations and model checks

## Tools & Techniques
- Microsoft Excel
- Financial Statement Analysis
- Financial Modeling
- Financial Ratio Analysis
- Common-Size Analysis
- Cash Flow Analysis

## Project Scope
The project involved organizing historical financial statement data, building formula-driven calculations, analyzing financial performance, and reviewing key financial trends over the selected period.
